# SaaS Gestão

Sistema administrativo pensado para empresas que precisam controlar vendas, estoque, atendimento, funcionários e organização interna em um único painel.

## Como funciona

O sistema foi desenvolvido para funcionar como uma plataforma web completa, com acesso por login, gestão de empresas, controle de produtos e movimentação de estoque, além de atendimento e painel administrativo.

### Fluxo principal

1. A empresa realiza o cadastro no sistema.
2. O administrador analisa e aprova a solicitação.
3. O usuário acessa o painel com login e senha.
4. O painel exibe informações gerais do negócio, como produtos, movimentações, tickets e status do sistema.
5. O gestor pode cadastrar produtos, acompanhar estoque, registrar movimentações e controlar o atendimento.
6. O sistema organiza as operações em uma interface centralizada, facilitando o acompanhamento da rotina.

### Funcionalidades

- Cadastro e aprovação de empresas
- Login com e-mail ou CNPJ
- Dashboard com informações gerais
- Gestão de produtos
- Controle de estoque
- Cadastro e acompanhamento de funcionários
- Área de atendimento e tickets
- Configuração do painel com logo, banner e informações da empresa
- Visualização de relatórios e métricas do sistema

## Estrutura do projeto

- PHP para a lógica do sistema
- MySQL para armazenamento dos dados
- HTML, CSS e JavaScript para a interface
- Arquivos principais na raiz do projeto

## Como será disponibilizado

A aplicação será entregue como sistema web funcional e, em seguida, pode evoluir para uma versão mobile em APK, conforme a etapa de desenvolvimento e testes.
